# 《Fish Shop》年轻成年女声慢速饱满版设计

## 目标

在已经交付的儿童女声版本之外，再生成一套语速稍慢、发音更饱满的美式女声朗读。用户已明确选择较年轻的成年女声，并接受它不再具有明显儿童音色。

## 声音方案

- 使用 Microsoft `en-US-AvaNeural` 美式女声。
- 合成语速设为 `-10%`，比当前儿童版的 `-5%` 稍慢。
- 音高设为 `-2Hz`，音量设为 `+2%`，只做轻微圆润化，不把声音压成低沉成熟的播音腔。
- 不使用低频 EQ、动态压缩、时间拉伸或播放速度调整，避免后期加工感。
- 不再要求保持儿童音色；声音目标是年轻、自然、清楚、圆润。

## 内容与节奏

- 完整保留原稿的所有英文单词和顺序，不润色、不改写、不漏句。
- 继续沿用已验证的 10 个自然段，不按原稿每个换行机械断句。
- 保持现有段间停顿，不额外加长静音；整体变慢仅由神经语音合成参数产生。
- `Wow!`、`Yum, yum, yum!` 保留轻微活力，感悟段和 `Thank you!` 自然收稳。

## 实现边界

- 在现有生成器中增加命名配置，不复制第二套全文和 PCM 拼接代码。
- 当前 `natural-child` 配置继续生成 `en-US-AnaNeural / -5%` 版本，行为和文件不变。
- 新增 `slow-full-young-adult` 配置，生成：
  - `deliverables/Fish-Shop-American-Young-Woman-Slow-Full.wav`
  - `deliverables/Fish-Shop-American-Young-Woman-Slow-Full.mp3`
- 保留现有儿童版与最初 Zira 版，方便试听对比。
- 继续通过一次性 `uv` 工具环境使用固定版本 `edge-tts==7.2.7`，不加入网站运行依赖。

## 验收标准

1. 新版使用 `en-US-AvaNeural`、`-10%`、`-2Hz` 和 `+2%`。
2. 新版音色比儿童版更饱满、稍成熟，但保持年轻自然，不像正式新闻播音。
3. 新版时长长于当前儿童版的 118.4 秒，且不超过 140 秒。
4. 原稿词序、10 个自然段和现有停顿配置保持一致。
5. WAV 为单声道 16-bit PCM、24000 Hz；MP3 与 WAV 时长差不超过 0.1 秒。
6. 无削波、回音、异常拖尾或尾部高能量。
7. 当前儿童版文件哈希保持不变。
8. 聚焦 Python 测试、项目 lint、Vitest 和生产构建全部通过。

## 失败处理

- `AvaNeural` 不可用时明确失败，不静默回退到儿童声、Zira 或其它成年女声。
- 若单段出现吞词或韵律异常，只重新生成该段，不对整篇做时间拉伸。
- 自动检查只能验证文本、参数、编码和信号质量；“更饱满、更自然”最终仍由用户试听确认。
